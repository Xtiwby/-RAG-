# 知源知识库系统功能验收资料

## 检索问答

知源知识库系统的前端采用 Vue 3，后端采用 FastAPI。用户在提问前选择一个或多个已授权知识库。检索过程首先规范化问题，再执行向量检索和 BM25 关键词检索。混合模式使用 RRF 融合两路排名，之后可按词项覆盖率进行规则重排。没有相关证据时，系统提示补充资料。

知识问答通过 Kimi 接口生成回答，并以流式方式展示。每个事实性句段末使用引用编号关联本轮检索证据。系统保存本人会话历史，支持继续提问、重命名、删除、反馈和导出问答记录。账户停用或密码重置后，原登录会话失效。

## 原文追溯

系统保存上传原文件的 SHA-256、结构化正文和文档版本。同名文档再次上传时创建新版本，旧版本仍保留。文档被划分为片段，每个片段保存章节、字符区间和独立 SHA-256。PDF 使用物理页码，Word 和 Markdown 按章节定位，不伪造页码。

引用编号跳转到对应文档版本的详情页面，命中片段以黄色高亮显示，并保留前后片段作为上下文。原文件下载、引用查看和检索都必须通过后端知识库授权校验。报告按模板章节检索证据，再调用 Kimi 生成正文；没有证据的章节明确标注待补充。报告支持导出 Word 和 Markdown。
