根据资料，当 Vue 响应式状态修改后，若代码需要等待 DOM 更新完成，应使用 **nextTick()** 全局 API [1]。
这是因为 Vue 的 DOM 更新不是同步的——Vue 会在"next tick"更新周期中缓冲所有状态的修改，以确保每个组件只会被更新一次 [2]。
因此，当你需要在状态修改后执行依赖更新后 DOM 的操作时，需要通过 `nextTick()` 来等待 DOM 更新完成 [1]。
