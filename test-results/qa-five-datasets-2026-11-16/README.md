# 知识问答五数据集端到端评测

本目录保存 2026-11-16 对知识问答模块开展的功能与性能测试结果。评测范围包括自定义车辆维修测试集、MIRACL、RAGTruth、RAGBench／DelusionQA 和 RGB，测试经过真实检索、答案生成、引用与证据校验链路，不是只测 RAG 召回。

## 结果摘要

- 功能测试：人工通过 105/110，人工通过率 95.45%，达到不低于 90% 的目标。
- 性能复测：完整响应 P50 为 6.76 秒，达到不高于 8 秒的目标。
- 性能复测：完整响应 P95 为 16.64 秒，尚未达到不高于 15 秒的目标；相同 79 题口径相较基线 26.27 秒改善 36.7%。
- 回归测试：99 passed，1 条第三方 Starlette/AnyIO 弃用警告。

## 文件说明

- `知识问答模块五数据集功能与性能测试报告_V2.0.md`：测试范围、方法、环境、结果、缺陷与结论。
- `功能测试人工复核.csv`、`性能测试人工复核.csv`：人工判定及理由。
- `功能测试结果/`、`性能复测/`：逐题结果、运行日志、自动汇总和运行环境。
- `运行五数据集端到端评测.py`：可复现评测入口，运行时需显式指定后端、模型和语料目录。
- `最终汇总.json`：最终指标摘要。

公开基准原始语料没有复制进仓库。来源清单和本次使用的小体积测试用例位于 `../../test-data/qa-five-datasets-2026-11-16/`，以避免提交模型缓存、重复大文件或受数据集许可约束的完整副本。

评测产物不包含 API 密钥、数据库、MinIO 对象、模型权重或虚拟环境。
