# 五数据集测试输入说明

本目录保存知识问答五数据集评测所需的可提交输入快照：

- `vehicle/`：车辆维修功能与性能测试用例，提供 CSV 和 JSON 两种格式。
- `sources/public-datasets-sources-manifest.json`：MIRACL、RAGTruth、RAGBench／DelusionQA、RGB 的来源、版本与校验信息。

完整公开数据集缓存没有提交到 Git。请依据来源清单从官方发布地址获取，并遵守各数据集许可证；本次实际抽样题目已固化在 `../../test-results/qa-five-datasets-2026-11-16/功能测试结果/测试用例.json` 和 `性能复测/测试用例.json` 中，便于核验本次结果。
