# 入库资料包（不含测试答案）

仅上传corpus/中的10份资料文件，不要上传本说明、manifest.json或licenses/。ZIP本身不作为系统的文档上传格式，请先解压。

资料来自ACL论文、SQLite、FastAPI、Vue、Elastic、scikit-learn、pypdf等公开技术来源，其中原文、净化文本及短中文摘编已在每份文件/来源清单中区分。保留licenses目录以满足署名及许可要求。本包不是项目实现说明，不含本项目运行数据或密钥。

本包不含问答参考答案、测试标签、OCR图片和重复文件。需要32道问答、8条核验样例、2个OCR样例和3个报告测试需求时，请使用同目录下的“RAG网络测试集_2026-10-31.zip”完整包，并阅读其中README.md。

先在系统创建独立测试知识库，再逐个上传corpus文件，等待解析与索引完成。建议按manifest中的group分为检索技术（retrieval）、后端与接入（backend）、前端（frontend）三个测试库。不要覆盖已有业务文档。

本包尚未自动导入知识库，未调用真实模型，未测问答成绩。原始资料、短引文和当前项目解析器的离线验证已在完整包中记录。
