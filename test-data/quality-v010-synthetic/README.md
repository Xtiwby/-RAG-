# 独立合成验收集（锁定版）

20份虚构设备手册，每份4道可答题和1道无项目实测证据题，共100题（80可答、20不可答）。中英文问题、参数与单位、否定条件、操作顺序和复合要点用于检查新质量门禁。

- 只有`corpus/`内的20份手册属于可入库语料；`labels/`、本文件和`manifest.json`不得作为检索证据上传。
- 所有设备与数值均为虚构验收场景，不是本项目实现、配置、客户或性能事实。
- 同一手册的问题有相关性，不等于100个独立事实。此集由开发者构建，不是第三方盲测。
- 不包含扫描PDF、真实Excel/PPT图表或图片；不能替代后续多模态验收。
- 文件/结构校验通过不代表模型正确率通过。本轮只准备、锁定并校验此集；不宣称执行了100题真实问答。
- 首次模型评估后如果依据这些题调整系统，应标为开发集，另留未参与调参的验收集。

从项目根目录执行`backend/.venv/Scripts/python.exe backend/validate_quality_acceptance.py`可校验问题数量、来源ID和哈希。构建脚本拒绝覆盖已有锁定集；修改语料需建立新版本，不要改动原标签来提高成绩。
