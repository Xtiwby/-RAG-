# 音视频引用定位与预览

更新日期：2026-11-24。关联需求：FR-QA-05、FR-UI-05；详细设计V1.2第4.6、5.10节的补充说明。

## 行为与设计

- 点击问答中的音视频引用编号，右侧展示原始视频或音频播放器和引用时间段，不以转写文本替代原文件预览。
- 将片段章节中的`HH:MM:SS – HH:MM:SS`转换为秒数，在播放器元数据加载后跳转到起始秒；视频抽帧OCR的`视频画面 HH:MM:SS`使用相同定位方式。
- 切换引用时按当前片段更新时间；零秒引用可以回到开头。缺少有效时间时标明未知，不将其显示为已定位到零秒。
- 文档原文页通过引用进入时也默认展示对应播放器；转写文字仍可从“检索片段”查看。
- 原件通过现有鉴权下载接口加载，不新增公开媒体地址。原件缺失或浏览器不支持编码时显示明确提示，不将转写文字伪装为播放结果。
- 播放需由用户操作，不自动播放。现有原件预览先下载原件后创建Blob URL，大文件首次打开仍可能等待。

实现：`ChatCitationPanel.vue`、`DocumentView.vue`复用`DocumentOriginal.vue`；`media-location.mjs`统一时间解析。此变更沿用已有转写片段时间，不新增视频语义理解能力。
