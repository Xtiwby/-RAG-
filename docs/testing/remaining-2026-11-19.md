# 知源系统遗留问题修复与实机验收（2026-11-19）

续验日期：2026-11-20。目录保留首轮日期，最新测试结果在原记录中更新。

本轮实际启动 PostgreSQL、pgvector、MinIO 和独立 worker，实际加载本地语义模型、OCR、离线转写模型，并调用当前配置的生成模型。测试均使用新建数据库、桶、合成资料和公开评测资料，没有切换或清理业务数据，也没有修改现有部署的密钥或已保存配置。

## 已修复的实现问题

| 问题 | 修复与验证 |
| --- | --- |
| 扫描、混合 PDF | 逐页识别没有文本层的页面；已有文字不改写，保留真实页码和原件。纯空白页不会触发 OCR 失败；识别失败明确报错。支持手动视觉解析、本地自动识别和页数上限。 |
| 重复上传 | 默认返回结构化重复提示；提供取消、复用已有文档、另建新版本。取消不留下文档或版本，复用仍检查知识库权限。 |
| S3 Range 完整性 | 返回任何字节前验证完整 SHA-256，再提供首部或后缀区间读取。固定对象版本，损坏返回 502，历史原件缺少哈希返回 409。验证缓存按版本和哈希隔离。 |
| 查询改写并发 | 不同事件循环不共享异步任务；一个请求取消不影响其他等待同一计划的请求。 |
| 报告核验两条路径 | legacy 与 workflow 共用分批核验实现，每批 8 句，核验失败保留证据不足占位。 |
| PostgreSQL 性能 | 由逐次连接改为进程内连接池，事务提交或回滚后归还，应用退出时关闭。 |
| 跨语言重排 | 使用与资料语言匹配的现有问题译文，避免只用中文原问题重排英文资料。 |
| 片段边界 | 启用相邻原文时，重排可参考同页或同节前后各最多 450 字；返回的原文片段、定位与哈希保持原样，邻文独立标记。 |
| 网页标题挤占证据 | 排除与章节名称相同的纯标题，保留标题作上下文；不再用一个函数标题替代正文机制说明。 |
| 复合问题证据不足 | 对每个子问题独立神经重排并保留直接证据；修复结果填充多加一条后挤掉保留证据的问题。相邻正文检索最多跨过两段纯标题，避免标题占用证据名额。 |
| 真实回答截断 | 对官方 DeepSeek 的已验证模型显式关闭默认深度思考，解决复杂题即使重试至 4096 仍截断的问题；保留一次格式失败重试，仍无效则拒绝发布。兼容第三方服务不自动添加此参数。 |
| 项目主体错置 | 明确区分外部教程、示例和本项目；快速核验模式下，涉及本项目实现或运行数据的问题额外执行独立核验，防止引用正确但主体错误。 |
| 转写环境缺失 | 增加离线 Whisper 与便携 ffmpeg 支持，模型预先下载并验证固定版本，处理请求不自动下载。 |
| Python 3.10 下载兼容 | 使用流式哈希代替仅新版本 Python 提供的 `hashlib.file_digest`。 |

## 真实服务验收

- PostgreSQL **16.15**、pgvector **0.8.6**；实际创建向量与全文索引，三种模式、中英文检索、审计筛选导出和独立 worker 索引均通过。
- MinIO 使用[官方固定标签源码](https://github.com/minio/minio/tree/RELEASE.2025-10-15T17-29-55Z)本机编译，独立私有桶启用版本控制。验证上传、下载、SHA-256、后缀 Range、同键新版本不改变旧原件、损坏版本拦截。
- 数据库事务异常后回滚、连接复用通过。真实 PostgreSQL 专项 **5 项全部通过**，包含时区和字面模糊匹配。
- Windows 本机没有 Docker，使用项目内隔离的运行环境启动服务，退出后停止；没有安装系统服务。

DeepSeek 参数依据：[官方思考模式文档](https://api-docs.deepseek.com/guides/thinking_mode/)。该服务默认开启思考，输出预算调整并不能替代请求模式修复；实际调用结果保留在生成验收记录中。

证据：[最终真实栈与整库结果](../../test-results/remaining-2026-11-19/stack-minio-corpus.json)、[数据库专项](../../test-results/remaining-2026-11-19/postgres-parity.xml)。续验脚本正常退出，并核对了项目内 PostgreSQL、MinIO 均无存活进程。

## 性能对照

同一小规模场景：4 并发、40 次请求，一半原件读取、一半关键词检索，使用真实数据库、对象存储和本地模型重排；零请求失败。

| 指标 | 连接池前 | 最终复测 |
| --- | ---: | ---: |
| 中位耗时 | 3703 ms | 101 ms |
| P95 | 5172 ms | 154 ms |
| 总耗时 | 38.12 s | 0.89 s |

这些结果限定于本机、短文本和已预热的小规模样本，不能作为大规模部署或长时间负载的容量承诺。GPU 模型首次加载仍有明显开销：BGE 向量模型冷启动约 21.27 秒；独立小样本的预热向量与 3 候选重排中位为 78.67 ms，该数值不等同于完整检索耗时。

证据：[修复前](../../test-results/remaining-2026-11-19/stack-minio-before-pool.json)、[最终复测](../../test-results/remaining-2026-11-19/stack-minio-corpus.json)、[模型测量](../../test-results/remaining-2026-11-19/local-models.json)。

另将全部 10 份公开原件上传至真实 MinIO，由独立 worker 写入 PostgreSQL，共 1461 个片段，索引耗时 19.91 秒。实际调用检索 API 验证 `postgresql-fts-pgvector` 路径，固定已有真实双语计划，不新增付费改写调用。

| PostgreSQL 整库场景 | 必要来源命中 | 中位耗时 | P95 |
| --- | ---: | ---: | ---: |
| 向量，32 次 | 25/25 可回答题 | 1.04 s | 1.98 s |
| 关键词，32 次 | 25/25 可回答题 | 0.53 s | 1.41 s |
| 混合，32 次 | 25/25 可回答题 | 1.19 s | 2.41 s |
| 混合，4 并发共 40 次 | 零失败 | 4.11 s | 7.56 s |

整库并发采用 8 个代表性问题轮换，包含复合问题，总耗时 47.31 秒。以上完整检索包括本地向量和神经重排，不含新一轮网络查询改写、回答生成或核验。并发时 GPU 模型排队明显，不能用小样本的 101 ms 描述整库检索。详见[整库逐题与并发记录](../../test-results/remaining-2026-11-19/real-postgres-corpus.json)。

## 真实模型与检索质量

本地实际加载 **BAAI/bge-m3** 与 **BAAI/bge-reranker-v2-m3**，运行在 RTX 4060 Laptop GPU，输出 1024 维向量。中文“去除空气水分”正确匹配英文除湿资料，语义相似度 0.6135，高于无关资料 0.2778、0.3234；重排相关资料 0.8911，无关资料约 0.000017。

公开资料评测包含 10 个来源、1461 个片段、32 个问题，其中 25 个可回答、7 个用于测试证据不足和范围边界。标签与标准答案不进入索引或推理。

| 模式 | 关闭改写的初测：命中全部必要来源 | 最终：命中全部必要来源 | 最终：命中全部指定示例引文 |
| --- | ---: | ---: | ---: |
| 向量 | 25/25 | 25/25 | 22/25 |
| 关键词 | 19/25 | 25/25 | 22/25 |
| 混合 | 25/25 | 25/25 | 22/25 |

最终配置为本地向量、本地重排、候选 40、主结果 5、相邻原文上限 6。先真实调用生成服务获得双语查询计划，再固定该轮计划比较上下文修复，避免重新生成计划的随机性混入比较；最终回放没有新增付费改写。三模式共 96 次检索。SQLite 路径最终完整检索中位耗时：向量 1.18 秒、关键词 0.42 秒、混合 1.20 秒，回放时间不含新一次网络改写。

“必要来源命中”不等于答案完全正确。“指定示例引文”是严格文本指标：例如 PDF 的 `dual-\nencoder` 与标签 `dual-encoder` 会造成字面未命中，另有复合题使用替代支持片段。保留该指标原始结果，没有改标签或宣称全部证据完整率为 100%。另行执行真实生成和逐句引用核验，结果见 [real-answers.json](../../test-results/remaining-2026-11-19/real-answers.json)。

当前 `.env` 配置的生成模型实际是 **deepseek-flash**；`KIMI_*` 是现有兼容接口变量名，`kimi-real.json` 是早期脚本命名。本轮没有把 DeepSeek 调用记作 Kimi 验收。真实六题 API 验证包含数值、否定、英文问答、复合问题和缺数据拒答，均通过；记录模型名称、输入与输出 token，未知消耗不记为零。

最终另跑 32 题真实生成，36 次模型调用均成功，没有结构化输出失败。逐题复核已发布正文：25 道可回答题均包含核心回答，7 道越界题未编造项目事实。Q024 已可同时说明 DPR 和 FTS5，Q025 已可说明接收文件不代表完成 OCR。生成与引用核验中位耗时 **1.44 秒**、P95 **3.17 秒**，不含检索；输入 77957 token、输出 4583 token，无未知 usage。少量候选句仍因引用或数字检查被过滤，Q002 虽已给出所问范围仍带不足提示；没有为提升表面通过率而放宽核验。这是固定公开测试库的一次核心答案复核，不是生产准确率或所有细节完整性的保证。详见[逐题复核记录](../../test-results/remaining-2026-11-19/answer-review.json)，记录绑定生成结果文件的 SHA-256。

证据：[初测](../../test-results/remaining-2026-11-19/real-retrieval.json)、[真实双语计划](../../test-results/remaining-2026-11-19/real-retrieval-before-context.json)、[最终检索](../../test-results/remaining-2026-11-19/real-retrieval-final.json)、[生成接口六题](../../test-results/remaining-2026-11-19/kimi-real.json)。

## OCR、音视频与 Office

- 真实中文扫描 PDF 识别出“被动散热”、`NX90217` 和 `21`；实际上传后由 worker 自动完成，原件哈希一致，重复提示与复用成功。
- 合成的真实 WAV、带音轨 MP4 均通过 ffmpeg/Whisper 处理，由实际上传与任务流程产生分段文字和时间定位。此轮音频为英文清晰合成语音，不代表中文方言或嘈杂录音识别率。
- 真实导出的 DOCX 由 LibreOffice 转成 PDF，中文、英文、数字、标题、引用及页脚可读，并检查了渲染图。此项覆盖实际 Office 转换；没有把 LibreOffice 结果记为 Microsoft Word 客户端验收。

证据：[扫描件](../../test-results/remaining-2026-11-19/real-scanned-pdf.json)、[上传与 worker](../../test-results/remaining-2026-11-19/multimodal-api.json)、[真实媒体与 Office](../../test-results/remaining-2026-11-19/real-media-office.json)、[版式渲染](../../test-results/remaining-2026-11-19/media/mixed-layout.png)。

## 回归与复现

最终后端 **241 项通过、1 项跳过**；跳过的是需要单独数据库地址的用例，已经在上述真实 PostgreSQL 专项中执行通过。历史 `*_V02.py` 是未接入当前应用的旧实现快照，保留但不纳入当前实现回归。前端 6 项测试和最终生产构建通过，依赖检查与差异空白检查通过。

```powershell
.\.venv\Scripts\python.exe check_real_answers.py
```

本地模型、OCR、ASR 依赖与准备步骤见 [README](../../README.md)。真实生成和查询改写会产生当前服务商费用；数据库与 MinIO 脚本仅使用新建测试数据。`check_multimodal_api.py` 只用于 8019 端口的独立测试服务。安装的数据库、编译工具、模型和服务数据在忽略目录中，不提交到源码。

要使用本轮质量配置，在「系统配置」启用本地 BGE-M3、本地重排和双语查询改写，将重排候选设置为 40、相邻原文上限设为 6。选择本地 OCR 可自动识别扫描 PDF；选择本地 Whisper 可离线转写。没有自动覆盖现有业务配置，这些选择需要按实际算力和服务费用采用。

Microsoft Word 本机客户端分页、复杂图形兼容性，以及生产规模长时间负载仍属于单独的环境验收边界；本轮不将它们写成已通过。
