# 界面与交互改造验收记录

日期：2026-10-31。范围：既有 Vue 3 前端；后端仍为 0.7.2。

## 改造结果

- 采用 Ant Design Vue 4.2.6；白色导航和内容面板、浅灰底、蓝色操作色、6–8px圆角、无重阴影。SVG替代平台相关字符图标；导航按工作空间、智能应用、调试与运维、系统管理分组。
- 桌面导航可收起，中等宽度使用图标导航，手机使用抽屉导航。顶栏账户菜单及后端健康检查保持精简。“服务在线”只表示后端健康，不表示模型实时连通。
- 工作台先展示上传、问答、新建报告，统计卡紧凑排列。最近报告默认不列归档项目；模板统计标明“模板版本”，不冒充可用模板数；内容占比按实际数量计算，未做检索质量评测时不编造质量指标。
- 知识库、文档、报告及模板使用统一表格、筛选、分页和空态。知识库编辑、文档上传/阶段事件、模板版本及结构预览进入抽屉。次要操作使用点击菜单，危险操作确认后才提交。知识库与文档筛选保存在地址参数中，返回时可恢复。
- 问答主区专注对话；历史会话、授权知识范围、高级检索和引用分开查看。保留三种检索模式、生成中止、反馈、导出及逐句核验记录。引用侧栏保留原编号，点击仍定位到对应文档版本和高亮片段。
- 报告编辑器默认目录/正文两栏，窄屏改为章节选择器。审阅进度与风险放入侧栏，保存状态保持可见，核验、候选、锁定、历史放入更多菜单。定稿和下载分成两步。失败报告重试后跟踪新报告ID，避免继续停留在旧失败记录。
- 保留人工最终决定权：缺证章节经当前修订人工审阅后仍可定稿；风险不伪装成模型通过。此轮只读检查已定稿报告12，不替用户修改、重新生成、审阅或定稿。
- 用户/角色/授权编辑使用抽屉；未保存修改关闭前提醒。审计使用基础筛选＋更多筛选、统一CSV/JSON导出菜单。系统配置折叠分组、显示保存状态、离开提醒；折叠分组中存在无效字段时自动展开以便校正。模型探测仍须明确点击，不自动产生调用。
- 登录、个人账户、检索测试、运行状态和原文页同步统一视觉；技术哈希、完整事件和重新切分等低频内容折叠。保留服务端授权，不以隐藏按钮代替权限校验。
- 路由按需加载；最终生产构建无大于500kB的单个JS文件。构建日志中两个公共JS块分别约323kB和468kB（未压缩），不将此等同于首次加载总量或实际网络性能测量。

## 效果截图

### 个人账户页专项调整

后续针对个人账户页重新设计：桌面采用账户概览与设置区两栏，窄屏切换为紧凑账户卡和横向页签；“基本资料”和“账户安全”分开显示，不再纵向堆叠两套表单。资料页加入只读账号/角色信息、显示名字数、保存状态、重置和未保存离开提醒；密码页加入重新登录说明、可键盘操作的显示/隐藏按钮、确认一致性提示。切换页签后重新遮罩密码，不保存密码草稿。

沿用原显示名与密码修改接口、8–128字符密码长度和所有会话失效策略，不更改后端认证或权限。校验辅助函数新增6项单元测试并全部通过，生产构建成功。两页签在1440/1024/768/555/375像素宽度共10组检查无整页横向溢出；浏览器验证页签键盘操作、空密码禁用提交、显示/隐藏与重新遮罩、显示名编辑后的按钮状态、离开取消及重置恢复。未实际提交显示名或密码变更，未对真实密码修改流程做端到端提交测试。

测试：在frontend目录执行 `node --test tests/profile-validation.test.mjs`。
