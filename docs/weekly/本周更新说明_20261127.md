## 3 当前运行配置说明

代码已经包含 PostgreSQL GIN、pgvector/HNSW、Embedding 缓存和可选 BGE Reranker，但当前数据库配置仍为 TF-IDF 与词法重排。当前 904 个片段均已建立关键词索引，尚未生成 pgvector 向量，因此：

- 关键词模式可使用 PostgreSQL GIN 索引。
- 向量和混合模式目前在应用层执行 TF-IDF、RRF 与词法重排。
- 若启用本地 `BAAI/bge-m3` 并重建索引，需确认缺失向量数量变为 0，混合检索才会进入 PostgreSQL FTS + pgvector 路径。

此项属于运行配置和后续性能优化，不影响本周问答对、登录锁定和问答链路功能提交。
